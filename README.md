# QGIS LAB Plugin

QGISで作業しながら、[QGIS LAB](https://qgis.mierune.co.jp/)の記事を読む・探す・保存するプラグイン。

## 使い方

1. プラグインを有効化し、ツールバーの本アイコン、または「Web → QGIS LAB」を選びます。
2. 左側の記事一覧から記事を選ぶと、右側の記事専用リーダーに本文と画像を表示します。
3. 検索欄でサイト全体をフリーワード検索し、12件ずつページを切り替えられます。入力が350ミリ秒止まるかEnterを押すと検索します。検索欄の左にある更新ボタンで再検索できます。タブ切り替えでは再取得せず、検索条件・ページ・結果を保持します。検索UIは「記事一覧」タブにのみ表示し、「保存済み」タブではすべてのブックマークを表示します。
4. 星ボタンで閲覧中の記事を保存。「保存済み」タブから開き直せます。もう一度ボタンを押すと解除します。
5. ホームには公式ロゴ、記事の選択・検索・保存の案内、プラグインの説明とインストール済みのバージョンを表示します。本文内の関連記事リンクから開いた記事も保存できます。

ドックは移動・フローティング可能です。左右の幅は区切りをドラッグして調整できます。

## 動作環境

- Windows・macOS・Linux、QGIS 3.44以降／QGIS 4.x、Python 3.9以降を対象としています。
- **追加インストール不要。QGIS同梱のQtとPython標準ライブラリのみ使用します。** Qt WebEngine・Qt WebKit・PyObjC・ブラウザの実行ファイルは不要です。
- 表示には共通の `QTextBrowser` を使用し、OS固有のブラウザ埋め込み処理はありません。
- ローカルではmacOS版QGIS 4.2で検証しています。Windows実機でのQGIS UI検証は未実施です。CIの検証範囲は下記参照。

記事一覧のサムネイルは、表示範囲に入ったものだけ非同期に取得します。同時取得は4件までで、画面外になった画像の通信は中止します。画像は最大320×180に縮小してセッション内に64件まで保持し、画像なし・取得失敗でも記事を開けます。サムネイルURLはブックマークにも保存します。

## 記事専用表示

元の記事HTMLの `<article>` 内にある `#content` から本文を抽出します。冒頭画像と記事ヘッダー、見出し、強調、箇条書き、表、コード、本文画像を表示します。元サイトの本文16px・行間32px、見出し32／28／24px、青いリンク、緑の概要枠・補足枠、バージョン注意枠、画像キャプションをQt対応のHTMLに変換します。本文幅は最大738pxで、ドックを狭めると文字と画像が追従します。サイトのナビゲーション・広告・JavaScript・任意のCSSは取り込みません。

- 本文と画像は非同期に取得します。画像は表示幅に合わせて縮小します。
- 本文内のQGIS LAB記事リンクはリーダー内で開き、ページ内リンクは見出しへ移動します。再読込にも対応しています。
- QGISのテーマに合わせて本文の背景色・文字色を引き継ぎ、概要枠・注意枠・リンクもダークモード対応の配色に切り替えます。テーマ変更時も閲覧位置を維持し、記事を再取得しません。
- 動画・動的な埋め込みは、リンク先URLをそのまま表示するクリック可能なリンクに置き換えます。サイト本来の操作や表示には「ブラウザで開く」を使います。
- 表示できない画像があっても本文を読めます。サイト構造が変わって本文を抽出できない場合は、理由と再試行方法を表示します。
- 記事本文の見た目を元サイトに近づけていますが、Qtのテキスト描画を使うため、角丸・Webフォント・サイト全体のレイアウト・動画再生・JavaScriptで生成される内容は完全には再現しません。

## データと通信

記事一覧を初回表示時に非同期取得します。通信中もQGISの操作を妨げません。30秒でタイムアウトします。

記事一覧・検索には `GET /_api/posts`（`freeword`・`page`・`limit=12`・`order=newest`）を使用します。検索条件を変えると前の通信を中止し、古い応答を無視します。失敗時は再検索できます。本文のオフライン保存は実装していません。記事を開く際や再読込時には本文を再取得します。記事一覧・本文・画像の取得はいずれもQGISのネットワーク設定を使用します。本文取得は5 MiB、画像は1枚8 MiB、画像の同時取得は4件までです。画像は最大100枚まで取り込み、表示用の画像データは64 MiBまで保持します。記事を切り替えると前の記事の通信を中止し、遅れて届いた応答を無視します。

ブックマークはQGISプロファイルの設定（`qgislab/`）に保存し、再起動後も残ります。記事一覧は永続保存しません。同じ記事のクエリ・アンカー・末尾スラッシュは同一のブックマークとして扱います。外部サイトへのリンクは標準ブラウザで開きます。

## インストール・開発

```sh
python3 scripts/package.py
```

生成された `dist/qgislab_plugin.zip` をQGISの「プラグインの管理とインストール → ZIPからインストール」で選択します。開発ディレクトリから直接読み込む場合は、生成ZIP版と二重に有効化しないでください。

```sh
python3 -m unittest discover -s tests -v
ruff check .
ruff format . --check
```

Qt/QGISがないPythonでも記事メタデータ・保存・パッケージのテストは実行できます。UI・ネットワーク・ライフサイクルのテストはQGISのPython環境で実行します。記事本文の表示、画像の読み込みと縮小、ナビゲーション、キャンセル、読み込み失敗を検証します。ブラウザエンジンのインストールは不要です。

## 構成とCI/CD

隣接する `kumoy-qgis-plugin` と `GTFS-GO` に合わせて、ルートの `classFactory` / `metadata.txt`、`pyproject.toml`、Ruff、QGIS Docker環境のテスト、GitHub ReleaseへのZIP添付を採用しています。

- `qgislab/articles.py`：記事の同一性、メタデータ、ローカル検索
- `qgislab/storage.py`：ブックマークの保存
- `qgislab/network.py`：サイズ・時間上限付きの非同期ネットワーク取得
- `qgislab/search.py`：記事検索APIの取得・ページ情報・記事メタデータの変換
- `qgislab/content.py`：記事本文の抽出とQt向けHTMLへの変換
- `qgislab/reader.py`：記事・画像表示とナビゲーション
- `qgislab/thumbnails.py`：表示範囲に応じたサムネイル取得とキャッシュ
- `qgislab/dock.py`：ネイティブQt UI
- `qgislab/plugin.py`：QGISへの登録と後片付け
- `scripts/package.py`：必要なファイルだけを含むZIP生成

CIはWindows・macOS・Linuxで純Pythonの解析・保存・ZIP生成を検証し、Linux上のQGIS 3.44／4.0 Dockerイメージで実際のQt UIとネットワーク処理を検証します。公開サイトへのアクセスはCIテストに含めません。Releaseタグ（例：`v0.1.0`）からZIP内のバージョンを設定し、ソースは変更しません。手動ワークフローではZIPをArtifactとして取得できます。

QGIS公式リポジトリへの配信は、登録準備後にRepository variable `PUBLISH_TO_QGIS=true` とSecret `QGIS_PLUGIN_TOKEN` を設定すると有効になります。GitHubのリポジトリURLが未確定のため、公開前に `metadata.txt` の `repository` / `tracker`、作者情報を確認してください。
